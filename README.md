# Moon Platform

Frontend landing page for سامانه ماه.

## Stack

React + TypeScript + Vite + MUI, with RTL support through Emotion and `stylis-plugin-rtl`.

## Run locally

```bash
npm install
npm run dev
```

## Status

Landing page structure, MUI theme, RTL setup, and the converted sections are in place. Two sections (`DailyImpactStatisticsSection` and `FeaturedProjectsSection`) are temporary compile-safe placeholders until their exact Anima source/data is restored. Image assets should be placed in `public/assets` using the names documented there.
