# Moon Platform

Frontend landing page for سامانه ماه.

## Stack

React + TypeScript + Vite + MUI, with RTL support through Emotion and `stylis-plugin-rtl`.

## Run locally

```bash
npm install
npm run dev
```

## Status

The MAH landing page structure, MUI theme, RTL setup, responsive sections, daily impact statistics, participation paths, featured projects, trusted partners, news, CTA, and footer are implemented.

The remaining integration task is to add the original Figma/Anima image and SVG assets under `public/assets` using the filenames documented in `public/assets/README.md`, then perform final visual QA against the Figma frame.
