# Support contact foundation
Public contact and company callback forms use the existing mobile OTP proof (single-use, rate-limited). The submission UUID is retained on ambiguous acknowledgement; with a fresh proof, exact replay returns the stored server-issued receipt; a different payload is rejected. No browser-generated success or localStorage ticket. Only active system_admin can list, read and update. Changes are audited transactionally and revision-checked. Admin can self-assign, set status and record an internal response; no message delivery is asserted. Closing requires a nonblank note. Public status lookup, routing to other staff, attachment handling and notification delivery are deferred until appropriate contracts and templates exist. The receipt is displayed only after successful response. No production deployment, deletion, payment, or external SMS template is added.
