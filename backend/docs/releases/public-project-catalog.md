# Public projects catalog
The public list/detail endpoints project the current locked, approved, published version of an active startup. Raw proposal JSON, evaluation and actor identities are not exposed. Only the three existing single-value basic form fields are projected; execution region is NOT relabeled as province. Missing metadata remains null. Funding amounts are strings and include only reconciled commitments in the target currency, consistent with landing KPIs. Funding progress is absent without a valid target; closeout determines active/closed status. Filters combine on the complete live collection, and pagination is real (six items, controls left, page numbers LTR). Landing highlights use the same projection. No mock image or fabricated metric is displayed. Project detail has no fake payment success or active payment path. Project cover images, independent province taxonomy, full project impact detail and real participation payment remain deferred. Company recommendation/demo sections and public support still need remediation. No deployment or data purge.
